# Flow - A Daily Schedule App

A **simple, user-friendly, sleek, and modern daily schedule app** designed to help users organize and manage their daily routines with ease.

The app allows users to **add, modify, and delete daily activities** while keeping track of important routines such as **sleep and wake-up times, exercise, yoga, reading, work, and other productivity-improvement activities**.

### Features

* User-friendly and intuitive interface
* Sleek, simple, and modern design
* Add, edit, and delete daily routines
* Track sleep and wake-up times
* Schedule exercise, yoga or other routines
* Plan reading and learning activities
* Organize work and productivity-focused tasks
* Manage daily routines from a single dashboard
* Designed to encourage consistency and better time management

The goal is to provide a lightweight and easy-to-use tool for building **structured, healthy, and productive daily routines**.
